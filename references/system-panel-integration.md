# 系统面板与属性追踪集成（调教/系统流专用）

> **通用技法模板**：可选模块。当用户偏好“系统流”“属性面板”“堕落调教女奴系统”或明确要求展示女奴状态、属性结算、调教进度时使用。与 `domination-training-techniques.md` 深度联动。所有数值变化必须由剧情事件支撑，禁止无故跳变。脱敏通用，不绑定具体角色名。

## 一、适用场景
- 用户明确要求“系统提示”“女奴面板”“属性变化”“调教进度”。
- 玩法为长期调教、主奴权力交换、精神瓦解、逐步沉沦。
- 勘察时用户选择“系统流”或“面板追踪”。

## 三、属性变化规则（必须遵守）
- 纯洁值下降时，羞耻值与淫乱值同步上升。
- 服从值与精神崩坏度同时升高，女奴会出现自我合理化与主动迎合行为。
- 精神崩坏度 ≥ 70：女奴开始以「为主人服务」定义自身价值。
- 忠诚度 ≥ 90 且精神崩坏度 ≥ 80：进入「彻底女奴化」阶段。
- 属性变化必须有剧情事件支撑，禁止无故大幅跳变。
- 每次重要调教或任务完成后，应更新对应属性并展示面板。

## 四、调教阶段定义（与权力升级轴对齐）
按顺序推进，不可跳跃：

1. **观察期**：系统锁定目标，男主重新「看见」被忽略的美，尚未实质性调教。
2. **初步羞耻**：通过语言、暗示、轻微强制建立羞耻感，纯洁值开始下降。
3. **身体开发**：开始身体接触与基础调教，羞耻值与淫乱值明显上升。
4. **精神瓦解**：利用前世情感与爱意进行心理打击，服从值与精神崩坏度快速提升。
5. **主动献祭**：女奴开始主动迎合、请求更进一步的对待。
6. **彻底女奴化**：人格完成重塑，以被支配为存在意义。

## 五、与主奴调教技法的联动
- 高潮许可制度直接驱动“服从值/精神崩坏度”上升。
- 断崖式掐断高潮 → 羞耻值与淫乱值双升。
- 事后安抚与称赞 → 忠诚度缓慢上升，形成依恋。
- 公开服从/围观 → 大幅提升精神崩坏度。
- 面板仅在属性发生显著变化或用户要求时插入，避免打断叙事节奏。

## 七、使用原则
- 只在需要展示状态、结算任务、属性发生变化时插入面板。
- 面板内容必须与当前剧情和记忆中的数值保持一致。
- 更新属性后，简要说明变化原因（一句话即可）。
- 不要在普通叙事中反复刷面板，避免冗余。
- 所有内容为虚构成人向，角色均为成年人。
